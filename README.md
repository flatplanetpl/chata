# Chata

Prywatny tracker mieszkań do wynajęcia dla Ołtaszyna i okolic.

## Dane

Strona korzysta z pliku `data.xlsx` jako źródła danych. Po aktualizacji arkusza wystarczy podmienić ten plik w repozytorium.

## Uruchomienie

Najprościej uruchomić lokalny serwer HTTP w katalogu repozytorium, np.:

```bash
python -m http.server 8000
```

Następnie otworzyć `http://localhost:8000`.
